## Features

- **Multi-source playback** through Lavalink: YouTube & YouTube Music, Spotify, Apple Music, Deezer, JioSaavn, SoundCloud, Bandcamp and direct URLs.
- **Components V2 UI** with zero embeds: now playing card, queue, search buttons, help menu, music control panel (`/setpanel`).
- **Slash and prefix commands**: 28 slash commands, plus 130+ prefix commands (default prefix `+`).
- **Queue control**: play, pause, resume, skip, previous, seek, loop, shuffle, volume, autoplay, similar tracks, 24/7 mode.
- **Playlists & favorites**: create, import/export, share by code, like songs, play your liked list.
- **Lyrics**: time-synced lyrics for the current track.
- **17 audio filters**: bass, nightcore, 8D, vaporwave, party, pop, rock, soft, speed, treble bass, electronic, radio, earrape, enhance, limiter, stabilizer and reset.
- **Radio stations** and a **search-engine selector** (Premium).
- **Spotify profile link** (`login` / `logout`) and Spotify playlist access.
- **Server tools**: anti-link protection, auto-responses, ignore list, custom prefix, AFK, bot name style / profile customisation.
- **Profile & stats**: commands used, listening time, badges, leaderboard.
- **Premium system**: user and server plans, free trial, vouchers, UPI payments via FamGateway.
- **Scale-ready**: hybrid sharding / clustering, multi-node Lavalink with node switching, auto-resume, backups.
- **Fun commands**: hug, pat, kiss, cuddle, ship and more.

## Premium

Lyrixa offers user and server Premium plans, a one-time 7-day user trial (`/trial`), and voucher codes. Plans are bought with UPI through FamGateway using `+buy`. See [TERMS.md](TERMS.md) for details.

## Privacy & Terms

Lyrixa reads message content to run commands, anti-link and auto-response features, and logs command usage to a private operator log. Full details are in [PRIVACY.md](PRIVACY.md), and usage rules are in [TERMS.md](TERMS.md).
